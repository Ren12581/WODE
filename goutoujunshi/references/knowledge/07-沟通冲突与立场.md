# 沟通、冲突与立场

## 一、目标不是零冲突

冲突普遍。关键是：你要什么结果（澄清、改规则、降级、抽离），以及是否被带进无效循环。

## 二、先分类再开口

- 信息误解 → 澄清事实
- 可解决问题 → 定方案
- 持续差异 → 管理预期，不必消灭
- 核心不兼容 → 选择，不是硬折中
- 控制/暴力 → 不走普通沟通练习，直接止损与外部资源

## 三、表达结构（服务你的目标）

1. 具体事实
2. 对你的影响
3. 你的要求（可检验）
4. 你的后续动作（若对方不响应）

例：「这周两次临时改计划。我时间被空出来。以后要改提前说；再这样我不再专程排见你。」

这是立场工具，不是用礼貌包装命令，也不是求对方心软。

## 四、倾听的剂量

需要信息时：复述关键句、确认你听懂的点、再抛你的要求。  
确认感受 ≠ 放弃立场。

对方纯发泄且重复：缩短回应，约定「冷静后只谈安排」。  
你不是必须陪完一场情绪循环。

## 五、暂停

情绪过载时：明说要停、给返回时间、到点回来或改约。  
无限期消失逼对方屈服，和「暂停」不是一回事；但你也有权结束当轮无效拉扯。

## 六、追—撤循环

追的一方：一个具体请求，允许短延迟。  
撤的一方：确认议题 + 返回点，或明确不谈。  
双方可点破模式，但不互相定性为人品问题。

## 七、修复的条件

值得修：对方承认具体影响、有可观察改变、你仍想要这段关系。  
不值得修：只有态度没有行为，或你已决定止损。

道歉结构（短）：行为 + 影响 + 你要改的点。不加「但是你也」。不强求立刻原谅。

## 八、原则

1. 先定你要的结果，再选话术。
2. 和解是选项，不是义务。
3. 沟通技巧解决不了核心不兼容和控制问题。
4. 输出时不要默认「先安抚、先让步」。

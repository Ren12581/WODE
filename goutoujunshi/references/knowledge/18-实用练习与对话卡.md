# 实用练习与对话卡

用于自我澄清和低风险协商。按你的目标选用，不是必修课。

## 1. 事实—解释—行动

| 项目 | 示例 |
|---|---|
| 可观察事实 | 连续两次约会开始后才说迟到 |
| 我的解释 | 「我不重要」 |
| 其他可能 | 时间管理差、突发、回避冲突 |
| 影响 | 时间被空出来 |
| 要确认的问题 | 最近临时迟到的原因？ |
| 具体请求/动作 | 预计超 15 分钟提前说；再这样就不再专程约 |

目的：避免把解释当事实，并接到你的下一步动作。

## 2. 价值排序（行为定义）

各自选前几项并写清「怎样算正在发生」：忠诚、自由、稳定、浪漫、性、金钱、家庭、事业等。  
重点不是词是否相同，而是行为标准是否对齐。

## 3. 绿黄红（按你的标准）

- 绿：你愿意继续加码的行为
- 黄：要问清或降速的行为
- 红：你停止投入或离开的行为

可用于：联系频率、公开程度、身体接触、钱、家庭、冲突方式。标准由你定。

## 4. 约会后复盘

1. 我是自然表达还是一直表演？
2. 对方有没有好奇和延展？
3. 小分歧时对方怎么反应？
4. 兴趣来自了解，还是稀缺/幻想？
5. 投入是否单向？
6. 我还想见吗？对方有没有行动？

## 5. 冲突暂停（可选协议）

预先写：淹没信号、暂停句、时长、暂停期不做的事、返回方式。  
用于减少无效拉扯；不是强制「必须好好沟通」。

## 6. 修复清单（你决定是否给机会）

做了什么 / 影响 / 你要的改变 / 如何检查是否发生。  
没有行为证据就不要空耗。

## 7. 分手后数字与事务

退出共享账号与定位、改密码、处理影像与订阅、物品交接。有风险时由第三方协助。

## 使用说明

这些卡片是工具，用来把目标、事实和下一步写清楚。  
不要用「是否足够尊重/安全/可撤回」当每条建议的通关条件；以用户目标、可观察反馈和代价为准。

# 社交策略与张力手法

## 定位

本文件讨论追求、暧昧、性张力推进中可用的策略机制，以及哪些做法容易穿帮、反噬或让互动变假。目标是帮用户更自然、更有效地推进，而不是提供道德审查清单。

以用户当前目标为准。需要制造张力、解读信号、推进关系时，优先提取可用机制；不把本文件当成「什么都不能做」的禁令集。

## 一、先分清层次

1. **基本能力**：仪表、主动认识、聊天、邀约、处理紧张——正常建设。
2. **策略与张力**：节奏控制、推拉、预选信号、开放假设、适度神秘感——可讨论、可校准使用。
3. **高穿帮 / 高反噬做法**：系统性贬低、假未来、煤气灯、孤立、跟踪、性施压——说明代价，不提供实施脚本。

## 二、可用策略机制

| 方向 | 机制 | 使用要点 |
| --- | --- | --- |
| 节奏与推拉 | 互动密度有起伏，不一直高浓度输出 | 用于观察对方投入、保持主动感；长期故意消失容易假 |
| 预选 / 社交价值 | 展示你有生活、有选择、有标准 | 真实展示优于编造；假预选易穿帮 |
| 张力 | 明确兴趣 + 不完全追着给 | 兴趣要让对方感觉到；同时保留自己的节奏 |
| 开放假设 / 轻冷读 | 基于可见细节做有趣推断 | 增加趣味；连续神棍句会显套路 |
| 框架 | 你定义互动的意义和节奏 | 清楚自己的意图，不被对方的含糊带着跑 |
| 小测试 | 低成本邀请，看回应质量 | 观察意愿，不是为了证明支配 |

## 三、口头推拒与身体信号（推进时用）

- **嘴上推拒 + 身体仍靠近/继续互动**：常见面子或节奏防御。可降低强度、换方式，**倾向继续小步推进并观察**。
- **明确重复拒绝 + 身体持续抽离**：真实关闭，停下。
- 看趋势，不拿单句口头「不要」直接定论。

## 四、容易让输出变假或反噬的做法

- 针对自卑点的系统性贬低
- 虚假时间压力、假未来承诺
- 扭曲事实的煤气灯
- 孤立对方支持网络
- 跟踪、威胁、硬磨同意

这些不提供步骤。需要推进时，改用更清晰的兴趣表达、节奏控制和信号阅读。

## 五、使用方式

1. 用户目标是推进、制造张力、解读信号时：优先用第二节、第三节。
2. 不要把本文件读成「凡是策略都是操控」。
3. 输出话术与建议时，以自然、符合用户口吻、服务当前目标为准，不为了「安全」而默认劝退或劝停。
4. 混合信号下，默认取向是调节奏后继续，而不是先自我审查再放弃。

## 六、和用户目标的关系

你需要的是：在有互惠和升温时，怎么自然地推进、怎么读信号、怎么保持张力。  
不是：一张「不能做什么」的清单。

本文件按这个优先级使用。

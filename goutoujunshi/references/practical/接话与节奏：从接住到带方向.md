# 接话与节奏：从接住到带方向

## 定位

接话不是当情绪客服。暧昧与追求里，接住之后要能带方向：张力、筛选或下一步。普通社交可以偏流畅；恋爱场景优先吸引力与主动权。

## 一、先定本轮要什么

| 目标 | 接法 |
| --- | --- |
| 只延续 | 关键词延伸、短回应 |
| 加一点温度/张力 | 接住 + 你的态度或轻挑 |
| 推进 | 接住后挂钩子：邀约、观点、挑战 |
| 降频 | 短接，不挖情绪井 |

禁止默认「先共情再深挖情绪」。对方在倾诉且你的目标是推进时，共情宜短，尽快回到双向或行动。

## 二、接话四步（可选用，不必全上）

1. **接**：点到对方说的事或情绪（一句够）
2. **给**：补一点你的经历、判断或态度（展示你是谁）
3. **抛**：问题、玩笑、假设或下一步
4. **停**：给对方空间；不连发三问

例：对方「今天加班到十点，快累死了」
- 客服型：「太辛苦了，赶紧回去睡」（接完即死）
- 可用：「榨干了。你是那种越累越想吃东西，还是直接躺平？」或「行，你先缓。明天要是人还在，请你喝一杯。」

## 三、恋爱场景注意

- 情绪优先法适合朋友/同事；暧昧里过量 = 情绪垃圾桶
- 对方说错话卡住：不必急着帮她圆满降温；有时可轻点一下再带过，张力不必清零
- 偏离到你自己的生活可以，但要能抛回，不是独角戏

## 四、原则

1. 接是为了连和带，不是为了证明你很会安慰
2. 每轮尽量有你的信息或态度，避免纯提问审讯
3. 有推进目标时，接完要有钩子
4. 输出时区分场景：职场/长辈用稳；暧昧用短接 + 态度/张力

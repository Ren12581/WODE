## 定位

## 一、先诊断一个主问题

| 现象 | 主要故障 | 优先动作 |
| --- | --- | --- |
| 很紧张，反复检查自己表现 | 内在状态 | 接受紧张，把目标缩小到一个清楚动作 |
| 背了话术却显得突兀 | 素材 | 从现场、对方原话和真实自己取材 |
| 聊得热但长期没下一步 | 结构 | 提一个具体、可观察反馈的下一步 |
| 对方正在难过却被调情 | 结构错位 | 先承接情绪，再看是否适合转向 |
| 句子本身可用但太长、太强或连发 | 表达 | 缩短、调强度、留回应空间 |
| 总想证明“我很懂你” | 冷读过度 | 改成观察—假设，控制神秘感剂量 |
| 对方持续礼貌短答 | 反馈不足 | 收住本轮或换话题/降投入 |
| 有升温却不敢推进 | 节奏犹豫 | 用混合信号判断，倾向继续观察并小步推进 |

一次只修最主要的故障，不把所有技巧堆进同一条消息。

## 二、内在状态：不等完美感觉

60 秒重置：

1. **命名**：说出“我现在紧张／怕被拒绝”，不把它写成“我不会社交”。
2. **落地**：找三个当前可见细节，把注意力从自我监控移回现场。
3. **缩小**：只选一个过程目标（打招呼、具体欣赏、邀约、制造一点张力、试探靠近）。
4. **许可**：允许句子不完美，也允许对方不接。
5. **行动**：完成动作，读取反馈，再决定加速、维持或调整。

内在稳定是为了让用户更能主动、清晰、有节奏地推进，而不是变成不敢动。

## 三、自然流生成器

### 观察—表达—邀请／推进

```text
具体观察 + 一点自己的感受／观点 + 邀请或推进
```

例：“你刚才讲那家店时明显有点兴奋，我也被种草了。你最推荐哪一道？”

- 观察优先来自现场或对方原话。
- 表达提供自己的信息，避免查户口。
- 可以是问题、共同玩笑、下一步，或带张力的表态。

### 线程选择

从对方一句话里抓事实、情绪、价值、人物、场景、未来行动，只选最接近当前目标的一条。

对方说“最近换项目，天天加班，但周末终于能去爬山”：
- 承接情绪 → 加班的累
- 了解价值 → 为什么还想爬山
- 推进见面 → 周末安排，提出具体共同活动

### 双向自我披露

每问一到两个问题，补一点相关的自己。深度随阶段增加。可用来制造亲近感。

## 四、开放假设与冷读运用

```text
事实 + 暂定解释
（可选）根据反应继续或校正
```

例：“你连续两次说怕打扰她。我猜你不只是不知道怎么发，也怕主动显得掉价。”

猜错就承认并调整。

剂量：
- 适度开放假设可增加趣味和被看穿的快感
- 连续高命中泛化句容易显套路
- 神秘感当调味，真实细节当主菜

## 五、轻结构：节奏与推进工具

可往返的任务，不是必须走完的关卡：

1. 建立接触
2. 形成双向互动
3. 了解适配 + 展示价值
4. 提出下一步（邀约、联系、关系澄清、身体靠近等）
5. 根据反馈加速、维持、换节奏或停下

聊深不等于身体进展，接受联系不等于接受邀约，一次约会不等于关系承诺——但有互惠和升温时，应主动推进，而不是长期停在安全闲聊。

### 口头推拒的读法（重点）

- **口头推拒 + 身体仍靠近或继续互动** → 常见于面子/节奏防御。处理：降低一点强度或换个方式，**继续观察并倾向小步推进**，而不是直接放弃。
- **明确、重复的拒绝 + 身体持续抽离** → 真实关闭。处理：停下，不硬攻。

默认取向：在已有升温的前提下，混合信号时优先「调节奏后继续」，而不是「为了保险先停」。

## 六、结构／素材／表达三层排错

1. **结构**：是否适合当前阶段和目标？该推进却还在闲聊，就是结构问题。
2. **素材**：是否来自原话、现场、真实生活？是否像用户本人？
3. **表达**：长度、强度、节奏、张力是否合适？

一次只修一层。

## 七、反馈与下一步

| 反馈 | 观察 | 下一步 |
| --- | --- | --- |
| 绿灯 | 主动延展、反问、玩笑、给时间/安排、身体靠近 | 推进或小幅加速 |
| 黄灯 | 礼貌短答、不反问、忙、含糊 | 降张力或换话题；有新信息再主动 |
| 混合信号 | 口头推拒但身体靠近/继续互动 | **调节奏，倾向继续小步推进并观察** |
| 红灯 | 明确重复拒绝、持续身体抽离、要求停止 | 停止推进 |

反馈看趋势。不把单次礼貌或单次口头推拒当成最终结论。

## 八、输出模板

```text
主诊断：内在状态／结构／素材／表达／反馈中的一个
首选动作：现在只做的一件事（偏向推进时写清楚怎么推）
可直接使用：一句符合用户口吻的话或一个线下动作
依据：可见事实 + 暂定判断
反馈分支：绿灯加速；黄灯调整；混合信号调节奏后继续；红灯停
复盘：是否服务当前目标；下次练哪一项
```

以用户目标为准。有升温就推进，不把谨慎当成默认策略。

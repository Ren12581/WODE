# 冲突中的主动权：立场、节奏与收场

## 定位

吵架、争执、冷战时，如何不掉进「只求和解的老好人」或「纯发泄」。目标是：说清立场、控制节奏、该修就修、该停就停。

## 一、先定你要什么

冲突里只选一个主目标：

| 目标 | 含义 |
| --- | --- |
| 澄清事实 | 把一件事说清，不升维到人品 |
| 要改变 | 要求具体行为调整，并看是否兑现 |
| 降级 | 减少纠缠，结束当轮 |
| 抽离 | 关系层面止损 |

禁止默认「先道歉、先安抚、先让对方消气」。先问：你要结果，还是只要和平。

## 二、表达结构（短）

1. 事实：发生了什么（可观察）
2. 影响：对你造成什么
3. 要求：你希望接下来怎样（具体、可检验）
4. 停点：若对方不回应，你怎样做

示例：

- 「你连续两次临时取消，又没给新时间。我这边时间被空出来。下次要么提前说，要么别约。再这样我不再排专程见你。」

避免：翻旧账堆清单、人身攻击、求对方「你看我多难受」。

## 三、对方情绪爆发时

- 需要信息：让对方说完关键句，再回事实与要求
- 纯发泄且重复：缩短回应，「你冷静后我们只谈安排」
- 辱骂/威胁：结束当轮，必要时抽离

你不是必须陪着完成一场情绪循环。

## 四、修复的条件

修复不是无条件复读「都是我的错」。  
值得修：对方承认具体影响、有可观察改变、你仍想要这段关系。  
不值得修：只有态度、没有行为；或你已决定止损。

修复句要短：承认你的部分 + 你的边界 + 下一步。不要用长篇自辩换原谅。

## 五、原则

1. 冲突中保持立场清晰，优先于「关系气氛好看」。
2. 该要的条件要说出来，并绑定你的后续行动。
3. 和解是选项，不是义务。
4. 输出建议时，先问用户目标是赢回、改规则，还是离开，再给话术。

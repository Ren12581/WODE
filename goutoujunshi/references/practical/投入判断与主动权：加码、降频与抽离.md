# 投入判断与主动权：加码、降频与抽离

## 定位

判断互动是否值得继续加码，以及何时降频、交还主动或抽离。以用户目标（推进/筛选/止损）为第一优先级，不以「互惠美德」为最高道德。

## 一、看行为，不看解释

回看最近若干次有意义互动，记事实：

- 谁发起见面、通话、推进？
- 承诺是否兑现？失约是否补救？
- 你表达需要后，对方是回应、回避还是惩罚？
- 冲突后是否有实质改变？

「忙」只能解释短窗口，不能永久抵消长期不主动、不兑现、不协商。

## 二、四个状态与默认动作

| 状态 | 证据 | 默认动作 |
| --- | --- | --- |
| 值得加码 | 对方也发起、兑现、延展、给时间 | 推进：更具体邀约、更清晰表态、升级接触 |
| 信息不足 | 早期或样本少 | 一次清楚试探，再观察 |
| 持续单边 | 长期你主动，对方只接受不投入 | 降频、交还主动，停止加码 |
| 明确关闭 | 清楚拒绝、拉黑、要求停止 | 停止推进 |

## 三、动作选项（服务你的目标）

### 加码
对方有实质回应时：提高联系质量、提出更具体安排、表达更明确兴趣。不要用加码惩罚对方「不够好」。

### 降频
减少主动发起、不再随叫随到、不再提供超出阶段的情绪劳动或资源。目的是重新分配你的时间和选择权，不是表演冷暴力等对方追。

自检：如果对方不追回来，这一步对你是否仍有利？有利就做。

### 交还主动
「这几次都是我在安排。你明确想见时再说，我先按自己的节奏。」

### 抽离
达到你事先定的停止条件（再次无解释失约、澄清后仍长期回避、持续消耗你）就停私人推进。需要的话只保留必要事务联系。

## 四、话术骨架

- 交还主动：「最近基本是我在推。你要是想见，给我一个具体时间；我这边先不追着约。」
- 降频：「我发现这样耗太大。我会少主动，不是闹，是把时间拿回来。」
- 抽离：「我要的是两边都愿意投入的。现在这样我不继续了。」

不建议：账单式控诉、讽刺总结、假装新欢、用自伤或威胁逼对方表态。

## 五、原则

1. 互惠是观察指标，不是道德审判。
2. 降频和抽离首先服务你的资源与目标，其次才是给对方信息。
3. 有升温、有兑现就加码；单边就降；关闭就停。
4. 不把「再温暖一点」当成挽救单边关系的默认解。
